O 5º Censo Nacional de População e Habitação e utilização de dados para o desenvolvimento nacional para construir um futuro para todos

Laos · 03/12/2025, 07:27:44

Parecer conjunto do Sr. Santiphab Phomvihane, Ministro das Finanças, Vice-Chefe do Comitê Gestor Nacional do 5º Censo de População e Habitação (CSP), Dr. Bakhtiyor Kadyrov, Representante do UNFPA no lançamento da Coleta Nacional de Dados de Campo dos 202

Opinião conjunta do Sr. Santiphab Phomvihane, Ministro das Finanças, Vice-Chefe do Comitê Gestor Nacional do 5º Censo de População e Habitação (CSP), Dr. Bakhtiyor Kadyrov, Representante do UNFPA no lançamento da Coleta Nacional de Dados de Campo de 2025.

A Coleta Nacional de Dados de Campo do 5º Censo de População e Habitação está programada para ocorrer de 3 de novembro a 28 de dezembro de 2025

O processo do censo é dividido em trêsfases: A primeira fase centra-se na recolha de dados sobre edifícios e habitações utilizando o Sistema de Informação Geográfica (SIG) para a criação de Áreas Enumeradoras (AE) e formação para formadores mestres, enumeradores e supervisores para garantir que compreendem os objetivos e metodologia da recolha de dados de campo do Recenseamento da População e Habitação (CSP). A segunda fase é a coleta de dados de campo da APS, e a terceira fase é a PósPesquisa de Enumeração (PSA), que está programada para ocorrer em janeiro de 2026.
