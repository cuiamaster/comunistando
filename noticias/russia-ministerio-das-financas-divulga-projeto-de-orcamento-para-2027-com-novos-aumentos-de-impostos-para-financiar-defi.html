Ministério das Finanças divulga projeto de orçamento para 2027 com novos aumentos de impostos para financiar déficit de guerra

Rússia · 24/09/2026, 10:56:37

Os aumentos de impostos propostos ocorreram apenas algumas semanas depois que o Kremlin insistiu que as autoridades não estavam discutindo nenhum aumento adicional.

O Ministério das Finanças da Rússia apresentou seu projeto de proposta de orçamento para 2027 na quinta-feira, introduzindo uma nova rodada de aumentos de impostos sobre renda passiva, comércio eletrônico e lucros inesperados corporativos, enquanto Moscou luta para financiar o aumento dos gastos militares.

Todos os anos, o Ministério das Finanças deve enviar seu projeto de orçamento federal para o próximo ano fiscal à Duma estadual da câmara baixa até 1º de outubro.

A proposta de 2027 delineia uma nova escala tributária progressivade 13%-22% sobre a renda pessoal passiva, incluindo juros de depósitos bancários, dividendos de ações, vendas de imóveis e negociação de valores mobiliários. Essas fontes de renda são atualmente tributadas a uma taxa de 13-15%.
